# astrbot_plugin_lettergame · 开字母小游戏

## 本插件大量代码为AI生成，且文档为AI辅助制作后人工修改，内容仅供参考，请仔细甄别。

基于 AstrBot 的开字母猜曲插件，由AI辅助开发
目前内置题库包含Phigros、Rizline、Milthm、Orzmic，可导入自定义题库

## 功能特性

- 开字母猜曲：随机抽题、开字母、猜答案、随机提示
- 每日挑战：同群同日题面固定，限开次数按题目难度自动计算
- 曲库查询：格式码查询、星号掩码查询、批量查询、可切换匹配模式
- 别名系统：别名添加、审核、删除、导入、导出
- 自定义题库：上传、编辑、删除、共享
- 预设出题：自制题目，可设置可开启的群与人员
- 比赛模式：答题计分与排行榜

## 安装与配置

方法一：把插件目录放进 AstrBot 的 `data/plugins/` 下，重载或重启即可。
方法二：从astrbot的插件市场下载本插件

>注意！插件本身不包含曲目别名数据！

## 快速开始

```text
/letter
```

发起一局开字母，若不指定数量则默认 15 题，从开字母发起人已启用的题库里随机抽取。开局后按提示输入本局限开数即可开始。

## 指令一览

### 开始游戏

| 指令 | 说明 |
| --- | --- |
| `/letter [数量]` | 开始一局开字母，可指定题目数量，默认 15。题库范围是你已启用的内置题库 + 自己上传的已启用自定义题库 |
| `/daily [题库名]` | 开始每日挑战，固定 15 题。可指定单个内置题库，不填则使用全部内置题库，插件会自动为题目难度打分并限制可开字母以动态控制难度。注意输入参数必须与对应内置题库名的英文名一致，可无视大小写。每日挑战凌晨4点重置，在超时后的下一次对bot使用开字母插件指令时会自动结束 |
| `/letterload [编号]` | 载入预设题目。默认只有作者可开启，作者可在 `/我的预设` 里设置可开启的群与人员 |

#### 限开数

`/letter` 与 `/letterload` 开局后，需在 60 秒内输入本局限开数：

```text
正整数：限制最多开多少次
0：禁止开字母
负数：不限次数
超时未输入：按不限次数开始
输入“取消”：取消本次开字母
```

### 出题

| 指令 | 说明 |
| --- | --- |
| `/上传预设` | 上传整套开字母题，仅私聊可用 |
| `/我的预设` | 查看并编辑自己上传的题目，回复序号进入编辑 |

`/上传预设` 格式：序号 + 题目，如

```text
1. Infinity Heaven
2. Retribution
+3. 这是一条装饰行
```

装饰行在序号前加 `+`。不需要手动写 `*`，Bot 会自动生成题面。

### 游戏进行中

| 指令 | 说明 |
| --- | --- |
| `/开 [字母]` 或 `/open [字母]` | 揭开该字符，一次只能揭开一个，且命令与参数之间必须加空格 |
| `/猜 [曲名]` 或 `/guess [曲名]` | 猜题，支持别名、字符相似度与大模型三次判定 |
| `序号 + 曲名` | 直接发「1. 曲名」或「1 曲名」也可以作答，不需要以命令开头 |
| `/tip` 或 `/提示` | 随机揭开一个尚未开出、且未答出题目里包含的字母 |
| `/end` 或 `/结束` | 结束本局开字母并公布全部答案，所有人可用 |

超过 15 题的题面将以图片形式发送，15 题及以下发送文字题板。

### 查询

| 指令 | 说明 |
| --- | --- |
| `/查询 [格式码]` | 如 `/查询 4-6-4` |
| `/查询 [掩码]` | 如 `/查询 ***** ****`、`/查询 **e** a***` |
| `/查询`（换行批量） | 以单独一行 `/查询`开头，之后每行「序号 + 查询内容」 |
| `/切换查询模式 [0/1/2/3]` | 切换匹配模式，不填参数时显示当前模式说明 |

查询模式：

```text
0：默认模式，严格逐字符匹配，* 排除已开字母
1：无视空格模式，空格视作不存在
2：空格视作 * 模式
3：无视已开字母模式，* 匹配所有字符
```

- 查询范围是已启用的内置题库 + 自己已启用的自定义题库
- 第一行 `guessed: ` 后的字符在对未开字符做判定时会被排除
- 当前会话游戏进行中查询功能会被禁用，但仍可在其他会话查询

## 权限说明

插件管理员默认为bot管理员，若进行了插件配置则以管理员列表的用户为准。管理员权限可以进行以下操作：

- 添加别名时直接生效，不需要审核
- 删除别名、审核别名申请
- 导入内置题库的别名
- 立即从官方动态拉取更新曲目与曲目写入题库的审核

题库创建者权限：对自定义题库进行改名、覆盖、删除题库、共享与取消共享。

## 附录

### 每日挑战难度系数

每日挑战的题面固定，但限开字母数会随难度系数动态调整：插件会给 15 道题各打一个难度分，相加后决定本局限开数。

```text
单题难度分 = 格式码系数 + 空格系数 + 别名系数 + 字符系数

格式码系数
    count <= 1                 -> 1.0
    count > 1                  -> min(count, 20)

空格系数
    max(0, 5 - 曲名空格数)

别名系数
    别名数 <= 1                -> 7.0
    别名数 > 1                 -> max(0, 7.0 - 0.5 × (别名数 - 1))

字符系数（去掉空格后逐字累加）
    英文字母                   -> 0
    汉字 / 日文假名 / 数字      -> +0.5
    ASCII 标点 / 全角符号       -> +1.0
    其它字符                   -> +1.5

    若整首曲子没有英文字母，再按「整曲是否全为同一类」追加一次
    全部为汉字 / 假名 / 数字    -> +1.0
    全部为标点 / 全角符号       -> +1.5
    全部为其它字符             -> +2.0
```

参数说明：

- `count`：这道题的格式码（如 `4-6-4`）在本局所用的所有题库里出现了多少次，即题库范围内有多少格式码相同的曲目
- `别名数`：这道题在所有题库里已有的别名条数
- 分数越高代表题目越长越杂，本局限开字母数就越多

限开数查表（15 题难度分之和）：

| 难度总分 | 限开字母数 |
| --- | --- |
| ≤ 180 | 5 |
| ≤ 220 | 7 |
| ≤ 280 | 8 |
| ≤ 330 | 10 |
| ≤ 390 | 11 |
| > 390 | 13 |

### 比赛模式单题得分

比赛模式可在所有开字母中生效，答对一题即时结算并显示本题得分，并在开字母结束后展示排行榜
若是预设开字母，在结束时还会将排行榜写进本地文件以供日后查看

```text
单题得分 = ( 基础分 × 难度倍率 × 已开字母倍率 × 小题已开字母倍率 × 时间倍率 × 热度
             + 积极参与奖励 ) × 提示倍率
显示时向上取整

基础分
    基础值 980
    若本次答题刷新了历史最高连击，在基础分的基础上额外获得20连击分作为基础分的一部分
    过快惩罚等级 n >= 1 时，使基础分 = max(200, 基础分 - 200 × n)

积极参与奖励
    积极参与计数 >= 3 时，获得额外100得分，该项为最终加算
```

各个系数：

- `难度倍率`
  - 预设题按曲名空格数：`max(0.2, 3.0 - 空格数 × 0.45)`
  - 非预设题按格式码稀有度：`min(3.0, 0.2 + √(count - 1) × 0.40)`，`count` 为该格式码在题库池中的出现次数，没有格式码时取 1.0
- `已开字母倍率`：`1 / (m + 1) + 0.8`，`m` 是本局全局已经开的字母数（去重）
- `小题已开字母倍率`：设 `r` 为这道题已被揭开的非空格字符占比，`r = 1` 取 0，`r = 0` 取 1，其余取 `1 / r - 1`
- `时间倍率`：`elapsed` 是「本局第一次有效操作」（开字母和第一次作答等，作答不看答案对错）到「这次答对」的秒数
  - `elapsed ≤ 1200`：1.5
  - `1200 < elapsed ≤ 2400`：`1.5 - (elapsed - 1200) / 2400`
  - `elapsed > 2400`：`max(0.5, 1.0 - (elapsed - 2400) / 3600)`
- `热度`：初始 1.0，答对 +0.5，上限 3.0；答错乘 0.5，下限 0.5
- `提示倍率`：`0.95 ^ 本局累计 /tip 次数`

其他修正项：

- 连击：答对时当前连击 +1，只有超过自己历史最高连击才会拿到连击分；答错连击归零
- 积极参与：与上一次答题间隔不超过 300 秒，积极参与计数 +1，否则重置为 1；计数 ≥ 3 时本单题额外 +100 分
- 过快惩罚：连续答题间隔小于 5 秒累计 3 次，过快等级 +1，之后每级扣 200 基础分；答错会清空 fast 计数，但等级保留

多人补正：

```text
排行榜总得分 = 本人所有单题得分之和 × 参与人数
参与人数 = 本局有过答题记录的人数（至少按 1 计算）
```

多人补正在总分阶段生效，不参与单题显示分的计算。人越多，每个人最后的总分倍率越高。
